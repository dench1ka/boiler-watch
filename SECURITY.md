# Учётные данные и публикация

Репозиторий содержит исходники, тестовые фикстуры и демонстрационные скриншоты. Настоящие токены Telegram, SMTP-пароли, настройки телефонов и ключи подписи в нём не предусмотрены. Значения вроде `fixture`, `example.org`, `example.invalid` и составляемые в тестах токены — искусственные данные для проверок; тесты не используют настоящий Telegram-аккаунт.

## На телефоне

- SMTP-пароль и токен бота шифруются AES-GCM с ключом Android Keystore.
- Неавторизованные пользователи и групповые Telegram-чаты не получают управление. Привязка выполняется одноразовым кодом с экрана телефона.
- Токен входит в URL запросов Telegram Bot API; приложение не пишет такие URL и тексты серверных ошибок в журнал.
- HTTPS-редиректы Telegram запрещены; SMTP требует TLS/STARTTLS и проверку сертификата/имени сервера.
- Фото и очередь находятся во внутреннем хранилище приложения. Резервное копирование и перенос данных отключены соответствующими правилами Android.

Эти меры не обеспечивают защиту устройства с root или скомпрометированной ОС. Исходная модель Redmi использует старую Android/MIUI: испытания на реальном устройстве и настройка доступа остаются необходимыми.

## При работе с Git

Не коммитьте токены, пароли, `.env`, `local.properties`, ключи подписи, снимки с персональными данными и полные журналы с настройками аккаунтов. Они исключены из репозитория либо должны оставаться локальными. Для примера приводите только фиктивные данные.

Если токен или пароль был опубликован, удаление строки из нового коммита не отменяет утечку через историю: отзовите секрет у провайдера и создайте новый. Токен бота можно заменить через @BotFather.

В публичном сообщении о проблеме не прикладывайте реальные токены, пароли и личные фотографии. Для начала достаточно версии Android/MIUI, версии приложения и описания последовательности действий с обезличенными ошибками.
