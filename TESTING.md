# Проверки версии 0.3.0

Версия 0.3.0 оставляет съёмку по времени и SMTP. Камера использует максимальный доступный размер и JPEG 100, исходное вложение не пересжимается. Удалены удалённые команды, их сетевой опрос, интерфейс и периодические таймеры.

## Сценарии

- Расписание: будущий таймер, повтор без дублей, независимый таймер повторной доставки, остановка наблюдения, восстановление после перезагрузки и смены часового пояса.
- Очередь SMTP: новое фото перед архивом, самый свежий снимок первым при восстановлении, остановка прохода при отказе, сохранение снимков и подтверждений после перезапуска, ограничение времени обработки, приоритет ближайшей съёмки.
- Совместимость старой очереди: уже подтверждённое письмо не повторяется; снимок без выбранной отправки на почту архивируется локально без перенаправления новому получателю.
- Обновление настроек: сохранение SMTP и расписания, удаление старых секретов и таймеров, сохранение выключенного/приостановленного состояния без неожиданного возобновления съёмки.
- MIME: исходные байты вложения сохраняются, адрес получателя фиксирован, отложенные письма помечены исходным временем.
- Устройство/эмулятор: Keystore, форма SMTP, навигация, черновик без пароля, максимальное разрешение камеры, съёмка с выключенным экраном, приоритет свежего снимка и срабатывание таймера во время доставки архива.

## Воспроизведение

```sh
python3 -m unittest discover -s tests -v
./scripts/build.sh
# Эмулятор должен иметь синтетическую заднюю камеру:
# emulator -avd YOUR_AVD -no-window -gpu swiftshader -camera-back emulated -camera-front none
./gradlew connectedDebugAndroidTest
# Только тестовый эмулятор Android 6–8.1; данные приложения будут очищены:
python3 scripts/test-reboot.py --serial emulator-5554
```

Локально выполнено **286 тестов без падений и пропусков**: 28 Python-проверок, 114 unit-тестов debug, 114 unit-тестов release и 30 инструментальных проверок (по 15 на API25 и API35). Lint: 0 ошибок, по 19 предупреждений для debug/release.

Дополнительно прошли настоящие перезагрузки API25: восстановление сервиса и расписания, автоматический JPEG без открытия приложения после загрузки, сохранение выключенного состояния. Установка 0.2.2 → 0.3.0 поверх предыдущего APK сохранила SMTP, расписание и исходные фото; старые таймеры и секреты удалены. Совместимость существующего Keystore-пароля отдельно проверена инструментальным тестом.

Локальные журналы находятся в `artifacts/verification`. [Обезличенная сводка 0.3.0](docs/testing/smtp-verification-0.3.0.json). Исторические JSON предыдущих версий сохранены в `docs/testing`; они не подтверждают текущую версию.

Полный прогон GitHub Actions: сборка debug/release/test APK, unit-тесты, Lint, эмуляторы API25/API35 и настоящая перезагрузка API25.

## Границы проверки

Физический Redmi 4A с MIUI и настоящий почтовый аккаунт проверяются владельцем. Эмуляторы не подтверждают читаемость показаний, ограничения MIUI и доставку в конкретный почтовый ящик. Автотесты не используют настоящие пароли и не отправляют письма внешним получателям.
